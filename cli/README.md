# idl-rs-cli

The `idl-rs` command-line tool (`idl-rs <noun> <verb>`): import logs, evaluate workbooks, generate synthetic rides.

This crate is part of the [idl-rs repository](https://github.com/saucyeng/idl-rs); see the repository README for the quick start and `docs/CLI-REFERENCE.md` for every command. AGPL-3.0-or-later.
